# 历史篇章资料说明

本版24条事件均以简短原创摘要表示事实，逐条链接到故宫博物院、国家图书馆、地方文旅机构等资料页面。没有复制图片或整篇文章。事件原始来源在 public/data/history.json 的 sourceTitle 和 sourceUrl 字段中。

时间按年组织；资料中的中国历法月日未直接换算为公历日期。1398年继位并不意味着该年为建文元年。1402年涉及建文纪年及朱棣恢复洪武纪年的变更，条目中单独标明。界面年号是年度导航标签，不能替代日级历法转换。

《永乐大典》1407年定稿与1408年誊抄完成分别建为事件；国家图书馆《史话》个别段落有明显纪年笔误，本版只取交叉核对后的编纂节点，未沿用其中1427年对应永乐十九年的写法。

城市坐标为人工选取的现代城市参考点。中央制度事件关联当时朝廷所在城市，不表示制度仅在那里实行；刘家港、昌平等事件在市级区域定位，不冒充考古遗址定位。本版不含时序行政边界，也未实现地名状态数据库。

西安城墙1370年初拓、1374年正式筑城、1378年竣工的区分采用中国邮政相关说明；1374—1378年工程记录支持持续事件的筛选演示。
