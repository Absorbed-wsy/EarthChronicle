# v0.1 · 2026-09-16

已实现：

- 本地3D地球、旋转缩放、城市标记聚合与定位。
- 1368—1421年示例篇章：5个地点、24条有出处的事件。
- 年份输入、时间轴、播放、年号显示、文本搜索、城市与类型筛选。
- 单年/前后五年/整个篇章的浏览范围；支持持续事件。
- 地质视图：MULLER2019模型0/66/120/200 Ma四个离线轮廓切片。
- 本机SQLite事件库，新增/删除个人记录、导入与导出。
- Windows启动与停止入口，附运行环境；可选局域网只读访问。

明确未实现：

- 古地形高度、随时间变化的海岸线、山脉形成模拟与板块边界动画。
- 完整历史资料、日级历法换算、历史政区疆界、人物关系库。
- 新建地点编辑器、自建事件的就地修改界面（可导出修改后导入更新）。
- Windows原生窗口、安装器、自动更新、公网账号与多人编辑。

验证范围：事件与地质数据结构检查；日期映射、持续事件筛选；事件写入、服务重启后持久化、导入更新与事务、导出、无效数据拦截、同源和编辑权限；浏览器历史/地质切换、搜索、新增保存、刷新恢复、手机宽度布局。具体最终验收结果见本次交付说明。
