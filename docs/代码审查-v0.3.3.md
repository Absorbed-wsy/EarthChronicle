# v0.3.3 代码审查

审查范围：自有前端、原生窗口、服务与鉴权、SQLite 导入导出、更新工具和源码构建流程。第三方 Cesium、Node 和 WebView2 不属于此次逐行审查范围。

## 已修复的问题

| 优先级 | 触发条件与影响 | 修复 |
| --- | --- | --- |
| P1 | 导入来自时钟偏快电脑的记录后再编辑，更新时间可能倒退，下一次合并会丢掉较新的个人修改。 | 每次编辑的时间戳严格晚于原记录，同毫秒的连续修改也能区分。 |
| P1 | 开启内容服务器的异步过程与关闭软件同时进行，可能在关闭后残留监听。 | 在端口探测和实际绑定完成后检查关闭状态，回收尚未交接的监听器。 |
| P1 | 更新工具在清单验证前退出软件，且未等待所有宿主和 WebView 进程退出；复制失败可能留下混合版本。 | 全量预检、限时等待本项目进程、完整备份后复制，失败回滚。 |
| P1 | 原生管理请求默认跟随重定向，自定义鉴权头可能被转发到另一来源。 | 禁止自动重定向；检查精确来源，后端退出后阻止继续向已释放端口发送凭证。 |

| P2 | 快速切换地质切片或返回文明历史，旧的异步图层可能在新状态之后挂上。 | 串行挂载并在挂载前后核对请求，重复加载共用结果，移除过期图层。 |

| P2 | 后台意外退出，窗口仍看似正常，用户无法判断为何不能保存。 | 保留页面和未保存输入，显示服务停止提示。 |
| P2 | 无效偏好请求如 JSON null 返回内部错误。 | 返回明确的客户端错误，并保留既有设置。 |
| P2 | 源码缺少依赖还原流程；忽略规则只排除数据库及日志，未排除浏览器配置和备份。 | 增加固定版本、校验摘要的准备脚本，排除完整运行数据目录、备份及构建产物。 |

## 验证方式

自动检查 33 项全部通过；原生请求回归通过，Windows EXE 编译成功。

服务测试使用真实临时 SQLite 与本机 HTTP 监听；覆盖权限、原子导入、禁止导入开启共享、更新时间和关闭竞态。前端测试使用可控异步 Cesium/DOM 替身，检查请求乱序、筛选与导入锁。原生测试使用真实回环重定向响应，证明凭证不会送往另一地址。更新工具使用隔离文件夹和故障注入验证不完整更新的回滚。

另外在一份不含本机数据的仓库副本中完成依赖还原、测试、编译与原生界面启动。实测开启共享后未保存表单保留；人为停止该隔离实例的后端后，状态提示出现且输入仍在。所有测试使用独立资料，结束后关闭相关进程。

## 仍需后续设计的边界

- 当前个人事件只支持公元 1—9999 年、一个已有地点和固定分类；这属于下一阶段的数据模型范围。
- 现有日期合并方案解决修改时间排序；删除同步尚无墓碑记录，重新导入含已删除事件的旧备份可能恢复该记录。
- 当前 EXE 依赖随包资源和运行组件，还不是安装包或单文件程序。
- 内置资料目前是明初示例与四个地质切片，不等同于完整通史或精确古地形。

这些边界写入后续规划，本轮不通过扩大功能来掩盖它们。
