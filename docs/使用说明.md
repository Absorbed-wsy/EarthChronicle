# 地球史书 v0.2

桌面项目：`桌面\EarthChronicle`

## 本地窗口与网页

双击项目中的 **启动地球史书.cmd**，打开独立的本地窗口。窗口由电脑已安装的 Microsoft Edge 承载，与网页端同步使用同一套阅读界面；它不是另行安装的原生窗口程序。

本地窗口在内容服务器关闭时也能阅读和管理资料。右上角齿轮进入设置，分为「外观与显示」「内容服务器」「数据库」。

若需要其他设备通过网页阅读，在本地设置中开启内容服务器，选择网页访问端口并保存，然后打开界面给出的地址。默认端口为 **8080**，首次升级后默认关闭。后续会记住你保存的开关与端口。端口被占用时会提示，保留原服务。

网页端只读，设置中仅提供外观与显示；不显示端口、数据库迁移和编辑入口。主机需运行程序，同一网络设备才能访问；软件不自动更改 Windows 防火墙。

关闭窗口不会停止服务；双击 **停止地球史书.cmd** 会一起停止本地程序和内容服务器。

## 外观与显示

人类历史和地球演化标签固定位置，不再随切换移动。皮肤已移入设置，仍提供晨光（默认浅色）、书页、夜航。

「显示选项」统一控制事件列表、详情面板、时间轴。隐藏后可随时通过齿轮或地图上的「显示选项」恢复。左右栏拖动竖向边缘调宽；时间轴拖动上沿调高低，也可在设置中使用高度滑块。分隔线支持方向键，时间轴高度范围为 116—300 像素。

本地显示设置保存在数据库中，随备份迁移。网页端的显示偏好只保存在当前浏览器，不改变主机数据。

## 一个数据库保存资料

运行中的历史资料、地理地点、地质模型切片、个人记录、本地显示设置和内容服务器配置统一保存在 **data/chronicle.sqlite**。SQLite 运行时可能暂时产生日志辅助文件，程序停止后会收拢。初次升级会自动将旧个人事件迁入。

内置历史资料与地质资料只读，界面和接口都不能修改或删除。个人记录可以新增、编辑、删除。「本机资料库 · 离线可用」提示及旧资料库入口已移除，旧的个人事件 JSON 导入导出已关闭。

在本地「设置 → 数据库」导出 **.sqlite** 文件，即可备份或迁移。导出会生成一致的完整快照，不需要手工复制正在写入的数据库。

导入数据库时：

- 校验数据库结构、完整性及内置只读资料；修改过的固定资料会被拒绝。
- 合并个人记录；同一 ID 保留修改时间较新的内容，保留目标机现有的其他个人记录。
- 恢复备份中的本地显示设置。
- 保留目标机当前内容服务器开关和端口，导入不会自动开放网络服务。

整库导入支持本版导出的数据库，最大 128 MB。来自不同内置资料版本的数据库暂不自动合并；v0.1 安装中的个人资料通过原地升级迁入。
