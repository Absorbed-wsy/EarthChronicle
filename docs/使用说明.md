# 地球史书使用说明

地球史书按地点和时间组织历史资料，提供文明历史与地球演化两种浏览方式。

## 启动与退出

双击 **EarthChronicle.exe** 启动。请保留完整的软件文件夹，不能只复制 `.exe` 文件。

- 点击窗口的 **−**：最小化至任务栏，点击任务栏图标恢复。
- 点击 **X**：隐藏至系统托盘，软件和已开启的网页服务继续运行。
- 双击托盘图标：恢复窗口。图标可能在任务栏右侧的隐藏图标区域中。
- 彻底退出：点击 **X** 隐藏窗口，再右键托盘图标，选择 **退出软件**。

## 地图与历史浏览

顶部 **文明历史 / 地球演化** 切换内容。地图支持 **3D 地球 / 2D 平面** 切换，拖动旋转或平移，滚轮缩放。点击 **N 指北针** 恢复北向上，点击全景按钮恢复整体视野。全景按钮只改变视角，不改变事件筛选。

在文明历史中，点击地图地点或左侧事件阅读详情。可搜索事件、城市和年号，并按地点、事件类型及时间范围筛选。时间范围包括 **这一年、前后五年、整个篇章**。浏览全部地点时，将地点选为 **全部**、时间范围选为 **整个篇章**，并清除不需要的搜索和类型条件。

时间轴支持点击事件节点、拖动当前点、输入年份及播放。小点表示事件年份，大点表示当前年份；到达时间边界后，相应跳转按钮禁用。地球演化的时间轴用于切换已有地质切片。

资料出处和精度说明可在事件详情、地质详情及 **关于资料** 中查看。

## 皮肤与布局

进入 **设置 → 外观与显示** 选择晨光、书页或夜航皮肤，默认晨光浅色。

**显示选项** 控制事件列表、详情面板和时间轴的隐藏与恢复。拖动侧栏分隔线调整宽度，拖动时间轴上沿调整高度；选中分隔线后也可使用方向键，Home / End 设为最小或最大尺寸。窄屏下部分面板会改为上下排列。

本地软件的皮肤、面板尺寸和显示状态随数据库保存；网页端的外观与布局只保存在当前浏览器中。

## 个人记录与固定资料

内置历史、地点和地球演化资料只读，不能修改或删除。地球演化界面只供浏览。

在本地软件的文明历史界面，点击 **记录事件** 新增个人记录，填写年份、地点、类型、事件记述和来源。选中个人记录后，可在详情中编辑或删除。请保留可核对的来源，并在记述中注明不确定之处。

个人事件目前支持公元 1—9999 年，地点和类型从已有选项中选择。

网页端始终只读，即使在同一台电脑上通过浏览器打开，也不能编辑记录、管理网页服务或导入导出数据库。

## 开启网页阅读

在本地 **设置 → 内容服务器** 中选择端口，开启服务并保存，随后访问界面显示的地址。本地软件在网页服务关闭时仍可使用。

默认端口为 **8080**，允许范围为 **1024—65535**。端口被占用时会提示，并保留原服务。开关与端口会保存，下次启动按保存值恢复；首次使用默认关闭网页服务。

其他设备访问时，主机须开机并运行地球史书，设备之间须能通过局域网通信。软件不会自动修改 Windows 防火墙。关闭内容服务器会停止网页访问；彻底退出软件也会停止服务。

## 数据备份与迁移

资料保存在软件文件夹的 **data/chronicle.sqlite**，包括内置资料、个人记录、本地显示设置和网页服务配置。

在本地 **设置 → 数据库** 中导出 `.sqlite` 文件进行备份；迁移时，在另一份地球史书中导入备份。使用界面导出即可获得完整备份，无需手工复制运行中的数据库。

导入将：

1. 校验文件结构、完整性及内置资料，拒绝损坏或固定资料被篡改的文件。
2. 合并个人记录；同一记录保留修改时间较新的版本，保留本机其他记录。
3. 恢复备份中的本地显示设置。
4. 保留本机当前的内容服务器开关与端口。

导入上限为 **128 MB**，支持本软件导出的兼容数据库；不同内置资料版本暂不自动合并。如需复制整个软件文件夹，请先通过托盘菜单彻底退出。

导入会合并备份中的记录；如果旧备份仍包含后来删除的个人事件，这些事件可能重新出现。

## 当前资料范围与限制

当前示范内容包含 **1368—1421 年的 24 条明初历史事件、5 个地点**，以及现代、6600 万年前、1.2 亿年前、2 亿年前的 **4 个地质切片**。

历史地点采用城市级近似坐标，不能当作事件遗址的精确位置。地质轮廓来自模型重建，尚不是连续板块运动动画，也不表示精确古海岸线、山脉高度或古地形。示范内容不是完整通史；没有事件的年份不代表没有历史事件。

资料来源与许可汇总见 [资料来源与第三方声明](../THIRD-PARTY-NOTICES.md)。

## 常见问题

**启动后未看到窗口**：先检查任务栏和系统托盘；窗口可能已最小化或隐藏。确认从完整的软件文件夹运行。

**提示缺少 WebView2**：安装 Microsoft WebView2 Evergreen Runtime 后重试。

**网页无法访问**：确认本地软件正在运行、内容服务器已开启，使用设置中显示的地址。其他设备还需检查网络连通性及防火墙；端口冲突时可在设置中更换端口。

**点击 X 后网页仍可访问**：窗口隐藏后服务会继续运行。要停止网页访问，可关闭内容服务器；要退出软件，请使用托盘菜单。

**地图无法显示**：按页面提示检查浏览器的 WebGL 2 与硬件加速支持，网页端可尝试新版 Edge 或 Chrome。地图不可用时仍可阅读事件列表和详情。
