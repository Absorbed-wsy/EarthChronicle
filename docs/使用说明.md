# 地球史书使用说明

地球史书按地点和时间组织世界历史资料，支持浏览内置资料和记录个人事件。

## 启动与退出

下载 Windows x64 便携包后，先完整解压到可写文件夹，再双击 **EarthChronicle.exe** 启动。请保留完整的软件文件夹，不能只复制 `.exe` 文件，也不要直接在压缩包中运行。无需安装 Node.js 或构建工具。

系统需要 Windows 10/11 x64、.NET Framework 4.8 和 Microsoft WebView2 Evergreen Runtime。首次启动自动创建数据库并导入内置历史资料；软件附带基础地图，详细道路和地形需要联网。

- 点击窗口的 **−**：最小化至任务栏，点击任务栏图标恢复。
- 点击 **X**：隐藏至系统托盘，软件和已开启的网页服务继续运行。
- 双击托盘图标：恢复窗口。图标可能在任务栏右侧的隐藏图标区域中。
- 彻底退出：点击 **X** 隐藏窗口，再右键托盘图标，选择 **退出软件**。

## 地图与历史浏览

地图支持 **3D 地球 / 2D 平面** 切换，拖动旋转或平移，滚轮缩放。点击 **N 指北针** 恢复北向上，点击全景按钮恢复整体视野。全景按钮只改变视角，不改变事件筛选。

选择国家、地区、城市或事件，以及返回全景时，地图通过约 2.4 秒的平滑过渡移动至相应位置，镜头缓缓启动并减速停下。镜头过渡在关闭 Windows 系统动画效果时仍保留；连续选择不同地点时，从当前视角转向最后选择的位置。

启动及返回全景时，地球直径约占地图显示区域较短边的 **92%**，并随区域尺寸调整，避免超出窗口。

软件附带全球基础地图与主要城市地名，默认联网逐级加载更详细的道路、街区和真实地形，无需下载详细地图包。点击地图右侧的 **斜** 切换倾斜视角查看山脉起伏，再次点击恢复俯视。按住 Ctrl 拖动也可调整倾角。平面模式不支持倾斜。

国外地区和城市优先显示中文与当地名称；名称相同时只显示一行，数据源没有中文译名时保留原名。点击城市名称会平滑放大并将城市移到画面中央；国家、地区名称按相应范围放大。地图名称采用矢量文字绘制，缩放时保持可读字号。**名** 按钮可显示或隐藏地区、城市和历史地点名称。

在 **设置 → 地图** 中选择底图、开关真实地形并设置画面质量。默认 **自适应**，根据屏幕像素密度和窗口大小设置清晰度；也可选择 **清晰优先** 或 **流畅优先**。镜头移动期间保持相同的绘制分辨率。首次打开地区的细节加载速度取决于网络和数据服务，绘制速度取决于显卡与屏幕分辨率。

软件附带约 33 MiB 的地图字形，在线与离线模式均从本地读取，无需联网下载字体。本地字形文件读取失败时使用系统字体。

自适应模式最高按 2 倍像素密度绘制，清晰优先最高 3 倍，流畅优先按 1 倍绘制。各模式同时限制总绘制像素，避免大窗口占用过多显存；画质设置不会改变地图数据的精度。放大或倾斜后请等待细节加载完成。

在线道路采用 OpenFreeMap 提供的 OpenStreetMap 矢量数据，地图最多放大至 19 级；超出源数据精度后只会重新绘制现有要素，不会产生更多真实细节。高程采用 Mapzen 多来源数据，许多地区为约 30—90 米级，并非建筑级三维模型；南北纬 85.051° 以外缺少该高程数据覆盖。地图展示现代地理，不随历史年份重建道路或地形。

在线地图和地形按视野加载，利用浏览器缓存和有限内存缓存减少重复请求，不提供区域批量下载。启动、断网或详细数据尚未就绪时显示内置基础地图，也可在设置中选择 **离线基础底图**。基础地图包括全球陆地、国家和 1,251 个主要城市，用于概览，地名显示中文与 Natural Earth 来源名称；其来源名称不保证是当地语言。在线细节就绪后使用更完整的当地地名。网络故障可在地图设置中点击 **重新连接**。数据服务由第三方提供，覆盖、译名和可用性可能变化。

## 按位置与时间检索

**世界历史** 默认选择中国，时间轴定位到本机当前年份。当年没有收录事件时，左侧列表和地图上的历史事件标记为空；可选择 **明** 或通过 **年份** 浏览现有资料。

1. 在左侧依次选择 **国家、地区、城市**；各级选择 **全部** 表示不限该级范围。展开国家选项后，可输入中文名、英文名或两位国家代码搜索；点击结果或用 ↑ / ↓ 选择后按 Enter 确认，按 Esc 取消。输入搜索词不会切换当前国家，清空搜索词可恢复全部候选；选择 **全部** 可跨国检索。国家或地区变化时，下级选项随之更新。地区采用现代行政区划作为检索参考，不表示事件发生时的疆界。
2. 在 **朝代/时期** 中限定时间区间，默认 **全部**。选择中国时显示中国朝代与时期；其他国家或国家为“全部”时，此项暂只提供“全部”。切换时期后，左侧默认列出该时期的全部年份。
3. 通过 **年份**、输入年份或时间轴节点定位到具体年份。年份选项列出当前检索范围内有记录的年份。左侧时间范围可选 **当前年份、前后五年、全部年份**；“全部年份”仍保留朝代/时期条件，并可继续按类型或关键词筛选。
4. 点击左侧事件，在右侧查看记述、地点与来源。列表按起始年份从近到远排列，每页最多 **40 条**，通过列表底部按钮翻页。

地图只显示选中年份发生或仍在持续的历史事件，并同时应用国家、地区、城市、类型、关键词和时期条件。跨年事件包含起止年份，例如 1369—1375 年的事件会在这七个年份出现。将左侧切换为前后五年或全部年份，不会让过去、未来事件同时堆积在地图上。底图中的普通城市和地区名称仍保留，可点击放大。

中国朝代与时期导航从 **公元前 770 年** 延伸至今，用于选择时间区间，并不表示已收录该时期的所有事件。并存政权的时间区间可能重叠；导航不重建历史疆界。国家选项可包含尚未收录事件的国家，选择后显示空列表。

## 时间轴

时间轴支持点击事件节点、拖动当前点、输入公元或公元前年份以及播放。小点表示有记录的年份，大点表示当前选中年份。

- **‹ / ›**：前一年或后一年。
- **« / »**：跳到筛选范围内上一个或下一个有记录的年份，适合跨越没有资料的年份。
- **▶**：逐年向过去追溯，再次点击暂停；到达区间起点后停止。
- **起点**：跳到所选时间区间的最早年份，保留当前筛选条件。
- **终点**：跳到所选时间区间的最晚年份，保留当前筛选条件。

到达时间边界后，相应跳转按钮禁用。公元前 1 年与公元 1 年直接相邻，不显示公元 0 年。

资料出处和精度说明可在事件详情及 **资料来源** 中查看。

## 皮肤与布局

进入 **设置 → 外观与显示** 选择晨光、书页或夜航皮肤，默认晨光浅色。

**显示选项** 控制事件列表、详情面板和时间轴的隐藏与恢复。拖动侧栏分隔线调整宽度，拖动时间轴上沿调整高度；选中分隔线后也可使用方向键，Home / End 设为最小或最大尺寸。窄屏下部分面板会改为上下排列。

事件列表和详情面板默认采用最小宽度，分别为 **240 像素、260 像素**，可拖动加宽。

时间轴默认高度为 **88 像素**，可拖动上沿在 **88–300 像素**之间调整，调整后的尺寸会保存。

本地软件的皮肤、面板尺寸、显示状态和地图设置随数据库保存；网页端的这些设置只保存在当前浏览器中。

## 个人记录与固定资料

内置历史和地点资料只读，不能修改或删除。

在本地软件中，点击 **记录事件**，再点击地图选择位置，填写标题、年份、地点名称、国家、类型和事件记述后保存。地区、城市及来源为可选项；来源名称留空时保存为“个人记录”。地图选点使用实际坐标，地区和城市用于检索，可填写已有城市或新增城市名称。引用已有城市时，事件坐标仍保留地图所选位置。当前选点范围为南北纬约 85.051°以内。

个人事件支持公元前 9999 年至公元 9999 年，以及包含起止年份的持续事件。选择公元前或公元后输入年份，不输入公元 0 年。类型包括政治、军事、外交、经济、社会、科技、文化、灾害，以及建都、营建、制度、航海、战争。

在左侧类型中选择 **自定义**，可检索自己添加的所有事件，并继续按国家、地区、城市和年份限定范围。自定义事件保留其原有类型，例如政治、文化；选择这些类型时也会列出符合条件的自定义事件。

选中自定义事件后，详情标题下显示 **编辑、删除** 按钮。编辑时可修改资料，点击 **重新选点** 修改地图位置；取消重新选点会保留原位置和未保存的资料。点击删除后，软件内会弹出显示事件名称的确认窗口；点击 **取消** 或按 Esc 可返回，确认删除后事件及其地图点同时移除。选点时可点击 **取消** 或按 Esc 退出。

自定义事件与地图位置保存在同一数据库中，随数据库导出、导入迁移。旧个人记录继续保留。请在来源和记述中注明资料出处与不确定之处。

网页端始终只读，即使在同一台电脑上通过浏览器打开，也不能编辑记录、管理网页服务或导入导出数据库。

## 开启网页阅读

在本地 **设置 → 内容服务器** 中选择端口，开启服务并保存，随后访问界面显示的地址。本地软件在网页服务关闭时仍可使用。

默认端口为 **8080**，允许范围为 **1024—65535**。端口被占用时会提示，并保留原服务。开关与端口会保存，下次启动按保存值恢复；首次使用默认关闭网页服务。

其他设备访问时，主机须开机并运行地球史书，设备之间须能通过局域网通信。软件不会自动修改 Windows 防火墙。关闭内容服务器会停止网页访问，并断开正在加载地图的网页连接；更换端口后请使用新地址打开网页。彻底退出软件也会停止服务。

## 数据备份与迁移

资料保存在软件文件夹的 **data/chronicle.sqlite**，包括内置历史、个人记录、本地显示设置和网页服务配置。

在本地 **设置 → 数据库** 中导出 `.sqlite` 文件进行备份；迁移时，在另一份地球史书中导入备份。使用界面导出即可获得完整备份，无需手工复制运行中的数据库。

导入将：

1. 校验文件结构、完整性和基础资料，拒绝不兼容或校验失败的文件。
2. 合并个人记录；同一记录保留修改时间较新的版本，保留本机其他记录。
3. 恢复备份中的本地显示设置。
4. 保留本机当前的内容服务器开关与端口。

导入上限为 **2 GiB（界面标为 2 GB）**，支持兼容的旧版数据库。导入用于合并个人内容与恢复显示设置，不会覆盖本机内置资料。如需复制整个软件文件夹，请先通过托盘菜单彻底退出。

导入会合并备份中的记录；如果旧备份仍包含后来删除的个人事件，这些事件可能重新出现。

## 当前资料范围与限制

内置资料包含 **1368—1421 年的 24 条中国明初历史事件、5 个地点**。其他国家的历史资料尚未收录。地点采用城市级近似坐标，不能当作事件遗址的精确位置。当前内容不是完整通史；没有记录的年份不代表没有历史事件。

资料来源与许可汇总见 [资料来源与第三方声明](../THIRD-PARTY-NOTICES.md)。

## 常见问题

**启动后未看到窗口**：先检查任务栏和系统托盘；窗口可能已最小化或隐藏。确认从完整的软件文件夹运行。

**提示缺少 WebView2**：安装 Microsoft WebView2 Evergreen Runtime 后重试。

**网页无法访问**：确认本地软件正在运行、内容服务器已开启，使用设置中显示的地址。其他设备还需检查网络连通性及防火墙；端口冲突时可在设置中更换端口。

**点击 X 后网页仍可访问**：窗口隐藏后服务会继续运行。要停止网页访问，可关闭内容服务器；要退出软件，请使用托盘菜单。

**地图无法显示**：按页面提示检查浏览器的 WebGL 2 与硬件加速支持，网页端可尝试新版 Edge 或 Chrome。地图不可用时仍可阅读事件列表和详情。

**道路地图连接超时**：桌面地图使用 WebView2 的系统网络设置，网页地图使用访问设备的网络。更改代理后可重新启动软件。在地图设置中也可重试连接或切换离线基础底图。
