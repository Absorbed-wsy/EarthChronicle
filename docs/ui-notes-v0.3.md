# 界面与显示说明 · v0.3.3

## 窗口与托盘

- 点击 **−** 正常最小化，窗口保留在任务栏；正常显示和最小化时不显示托盘图标。
- 点击 **X** 隐藏到托盘，软件及内容服务器继续运行。双击托盘图标恢复窗口，恢复后隐藏托盘图标；右键托盘图标可退出软件。
- 隐藏与恢复使用同一个窗口，不再重建窗口。
- 使用 `EarthChronicle.exe --background` 可直接在托盘后台启动。

## 地图与时间轴

- 顶部“文明历史 / 地球演化”切换内容；右上记录事件按钮缩小，与设置图标等高。
- 地球视图可拖动旋转，平面地图可拖动平移；滚轮缩放，点击地点或事件阅读资料。
- 地图区域不显示模式标签、现代地表参考或 Müller2019 浮签；模型与资料来源保留在详情和“关于资料”中。
- 地图上的“查看全部地点”按钮已移除；地点筛选选择“全部”，时间范围选择“整个篇章”，再点击全景按钮，可浏览全部地点。全景按钮只调整地图视角，不改变事件筛选。
- 时间轴小点表示事件年份，大点表示当前时间。浅色与书页皮肤使用深紫色当前点，夜航皮肤使用白色当前点。
- 可点击年份节点、拖动当前点、输入年份或使用播放按钮切换时间。
- 到达时间范围边界后，相应方向的跳转按钮禁用；重复跳转到当前年份不会改变选中事件或地图。
- 拖动时间轴上边缘调整高度；也可选中分隔线后使用上下方向键，Home / End 设为最小 / 最大高度。
- 侧栏同样可拖动分隔线调宽。地图区域已移除收起列表、收起详情按钮；“设置 → 外观与显示 → 显示选项”是事件列表、详情面板和时间轴隐藏与恢复的统一入口。

## 设置的保存位置

- 本地窗口的皮肤、面板显示状态和尺寸保存于数据库，随数据库迁移。
- 网页端的外观和布局只影响当前浏览器，不改变主机设置。
- 内容服务器与数据库管理仅供本地窗口使用。服务器开启后，其他浏览器可通过设置中显示的地址阅读内容。
- 网页访问端口允许使用 1024—65535；保存后生效。端口被占用时保留原服务，并显示错误。

## 数据与迁移

- 历史资料、地质切片、个人记录与本地显示设置保存于同一个数据库。
- 导入本软件导出的 `.sqlite` 文件会合并个人记录，同一记录保留较新的修改，其他已有记录不受影响；显示设置使用备份中的设置。
- 内置历史和地质资料只读，导入时会校验；当前内容服务器开关与端口不会被备份更改。
- 个人事件应保留来源与不确定性。地点为城市级近似位置，并非精确历史遗址坐标。
- 地球演化显示模型重建的陆块轮廓，颜色只用于区分陆块与背景，不表示精确古海岸线或古地形。各模型与资料来源仍可通过“关于资料”查看。

界面仅保留操作名称、运行状态、结果和错误；上述说明集中保存于文档。
