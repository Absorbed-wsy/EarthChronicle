# 地球史书 v0.3.3 使用说明

## 启动、本地窗口与托盘

项目位于桌面的 **EarthChronicle** 文件夹。双击 **启动地球史书.cmd** 或 **EarthChronicle.exe** 打开软件。本地界面由 Windows 原生窗口承载，与网页界面使用同一套地图和阅读功能。

- 点击窗口的 **−**：正常最小化，保留任务栏窗口，可点击任务栏恢复。
- 点击 **X**：隐藏到系统托盘，软件与已开启的内容服务器继续运行。
- 双击托盘图标：恢复本地窗口。图标可能位于任务栏右侧的隐藏图标区域。
- 右键托盘图标，选择 **退出软件**：关闭窗口、后台服务和内容服务器。
- 双击 **停止地球史书.cmd**：退出正在运行的软件。
- 双击 **启动局域网共享.cmd**：启动软件，并开启之前保存端口的内容服务器。

正常显示和最小化时没有托盘图标；仅关闭窗口到后台，或使用 `EarthChronicle.exe --background` 显式在后台启动时显示。恢复本地窗口后，托盘图标隐藏。

隐藏与恢复使用同一个窗口，不再重建窗口。

运行时请保留整个项目文件夹，不能只复制启动文件或 `.exe`。程序需要随包的地图、组件与运行环境。

## 开启网页访问

本地软件不依赖内容服务器即可浏览和管理资料。若需要用普通浏览器或其他设备阅读，进入 **设置 → 内容服务器**，选择端口、开启服务并保存，随后访问显示的地址。

网页端口默认 **8080**，可设为 **1024—65535**。端口被占用时会提示，原有服务保持不变。服务器开关与端口会保存，下次启动按保存值恢复；新数据库默认关闭网页访问。

网页端始终只读，即使浏览器与软件位于同一台电脑，也不能编辑记录、改变服务端口或导入导出数据库。网页的主题和布局设置仅影响当前浏览器。关闭内容服务器后，普通浏览器不能继续读取资料；本地软件仍可使用。

其他设备访问时，主机须开机且地球史书仍在运行。设备之间需能通过局域网通信；Windows 防火墙或路由器隔离设置可能影响访问，本软件不会自动更改这些设置。

## 地图、时间轴与显示

顶部 **文明历史 / 地球演化** 在固定位置切换。地图可切换 **3D 地球** 和 **2D 平面**；拖动旋转或平移，滚轮缩放。点击 **N 指北针** 回到北向上，点击全景按钮回到整体视野。地图区域不再显示模式标签、现代地表参考或 Müller2019 浮签；模型与资料来源保留在详情和“关于资料”中。

地图上的 **查看全部地点** 按钮已移除。需要浏览全部地点时，在事件列表的地点筛选中选择 **全部**，时间范围选择 **整个篇章**，再点击全景按钮恢复整体视野。全景按钮只调整视角，不改变事件筛选。

文明历史的时间轴可点击节点、拖动当前点、输入年份或播放。小点表示资料的事件年份，大点表示当前时间；当前点使用与事件点不同的高对比颜色。浅色和书页皮肤使用深紫色，夜航皮肤使用白色。到达时间范围边界后，相应方向的跳转按钮禁用；重复跳转到当前年份不会改变选中事件或地图。

时间轴直接拖动上边缘调整高度。选中分隔线后，也可用上下方向键调整，Home / End 设为最小或最大高度。设置中不再重复提供高度滑块。

左右侧栏拖动分隔线调整宽度。事件列表、详情面板和时间轴的隐藏与恢复统一通过 **设置 → 外观与显示 → 显示选项** 控制；地图区域已移除收起列表、收起详情按钮。主题同样位于 **设置 → 外观与显示**，提供晨光、书页、夜航，默认晨光。

本地软件的主题、显示状态和面板尺寸保存到数据库，可随备份迁移。网页端的这些偏好保存在当前浏览器中，不会更改主机设置。

## 记录与只读资料

内置的文明历史、地点与地球演化资料为固定资料，不能修改或删除。地球演化界面只提供浏览功能，不显示个人记录入口。

在本地的文明历史界面，可通过右上角 **记录事件** 新增个人事件，并编辑或删除个人事件。记录按钮已缩小至与设置图标一致的高度。填写发生年份、地点、分类、说明和来源。个人记录应注明不确定之处，并保留可核对的资料来源。网页端不能进行这些编辑。

本版示范资料包括 5 个地点、24 条明初历史事件，以及现代、6600 万年前、1.2 亿年前、2 亿年前的 4 个地质切片。地质切片尚不构成连续的板块运动动画。地图使用城市级近似位置，不是精确历史遗址坐标；地质轮廓来自模型重建，陆块颜色不表示精确古海岸线或古地形。

资料来源与精度说明见 [历史来源](history-sources.md)、[地质来源](geology-sources.md)。界面中的“关于资料”保留来源入口；一般操作说明集中于本文和 [界面与显示说明](ui-notes-v0.3.md)。

## 数据库备份与迁移

所有业务资料统一保存在 **data/chronicle.sqlite**：内置历史、地点、地质切片、个人记录、本地显示设置和内容服务器配置。首次升级会将旧个人资料迁入。`public/data` 保留首次建库和旧版升级所需的种子资料，运行页面从数据库读取，不通过网页公开这些源文件。

SQLite 运行期间可能生成辅助日志文件；它们是数据库写入过程的一部分。WebView2 也会生成浏览器缓存，程序会记录本次运行状态；这些临时信息不是资料库，不承载个人事件或内置资料。

进入本地 **设置 → 数据库** 导出 `.sqlite`，即可获得完整、一致的备份，无需手工复制正在写入的文件。迁移到另一台机器时，在该机器的地球史书中导入此文件。

导入时会：

1. 检查数据库结构、完整性和内置资料，拒绝损坏文件或篡改过的固定资料。
2. 合并个人记录；同一记录 ID 保留修改时间较新的版本，并保留目标机器上其他个人记录。
3. 恢复备份中的本地显示设置。
4. 保留目标机器当前的内容服务器开关与端口，不因导入自动改变网络访问配置。

导入上限为 **128 MB**，支持本软件导出的兼容数据库。不同内置资料版本暂不自动合并。旧的个人事件 JSON 导入导出入口已经移除。

如需手动复制整个项目，先运行停止脚本，或点击 **X** 后通过托盘菜单退出软件，再复制文件夹，避免只复制尚未合并日志的数据库主文件。

## 常见问题

**双击启动文件后未出现窗口**

先查看任务栏，点击地球史书恢复最小化窗口；若此前已点击 **X** 隐藏到后台，则双击托盘图标恢复。请从完整项目目录运行，确认 `EarthChronicle.exe`、`runtime` 和相关组件仍在。本地窗口所需的内部端口会自动选择，通常不需要调整；网页内容服务器的端口仍由本地设置控制。

**提示缺少 WebView2 运行环境**

本版使用 .NET Framework 4.8 和 WebView2 Evergreen Runtime。当前开发电脑已安装 WebView2 Runtime；迁移到其他电脑时可能需要安装。安装包可从 [Microsoft 官方 WebView2 下载页](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 获取，运行要求见 [Microsoft 分发说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。SDK 组件已经随软件提供，不能替代完整运行环境。

**网页仍显示旧的管理设置**

关闭旧标签后，通过本地设置给出的内容服务器地址重新打开，或强制刷新页面。页面文件禁用缓存，服务端同时检查本地软件身份；即使旧页面还显示管理入口，也不能修改数据。普通浏览器不会因访问本机地址获得本地权限。

**关闭窗口后网页仍能访问**

这是托盘后台运行的预期行为。若要彻底停止，右键托盘图标选择退出软件，或运行停止脚本。

## 实现与检查范围

原生外壳使用 WinForms / .NET Framework 4.8，网页内容使用 WebView2 SDK 1.0.4191.47 与系统 Evergreen Runtime，数据服务使用随包 Node.js，地图使用 CesiumJS。本地身份凭证仅在进程内存中使用，不放入网页地址、页面脚本或数据库。

命令行 `EarthChronicle.exe --share` 用于启动并开启保存端口的内容服务器，`EarthChronicle.exe --background` 用于隐藏窗口并显示托盘图标，`EarthChronicle.exe --quit` 用于退出已有实例。

服务回归检查可通过 `runtime/node.exe --test tests/server.test.mjs` 运行。v0.3 的自动检查覆盖旧数据迁移、个人资料编辑、固定资料保护、整库合并、端口冲突、本机普通浏览器权限隔离和内容服务器只读限制。原生窗口、托盘与具体电脑上的网络连通性需结合实际运行检查。
